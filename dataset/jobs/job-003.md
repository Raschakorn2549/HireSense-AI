# Machine Learning Engineer

**Department:** Data Science
**Type:** Full-time
**Location:** Bangkok (hybrid)

## About the role

We are hiring a Machine Learning Engineer to take models from notebook to production.
You will own problem framing, feature work, offline evaluation and the hand-off to
serving. We care more about whether you can measure a model honestly than about how
many frameworks you have touched.

## Responsibilities

- Frame business problems as supervised learning tasks and define the evaluation metric
- Build and iterate on models with Python and scikit-learn
- Prepare and validate training data using Pandas
- Design offline evaluation that reflects production conditions, and report uncertainty
- Document model limitations and failure modes for stakeholders

## Requirements

- 2 to 4 years of applied machine learning experience
- Strong Python
- Production or near-production experience with scikit-learn
- Solid grounding in machine learning fundamentals, including overfitting,
  cross-validation and class imbalance
- Comfortable manipulating tabular data with Pandas
- Working knowledge of statistics
- Bachelor's degree or higher in Computer Science, Statistics, Mathematics
  or a related field

## Nice to have

- Deep learning experience with PyTorch
- Experience tracking experiments with MLflow
- Feature engineering at scale
- Familiarity with Docker for packaging models
