# Data Engineer

**Department:** Data Platform
**Type:** Full-time
**Location:** Bangkok (hybrid)

## About the role

The Data Platform team owns the pipelines every analyst and model depends on. As a
Data Engineer you will build and operate those pipelines, and you will be the person
who knows why a number in a dashboard changed.

## Responsibilities

- Build and operate batch data pipelines orchestrated with Apache Airflow
- Write and optimise SQL transformations against the warehouse
- Develop pipeline code in Python, with tests and clear failure handling
- Design warehouse schemas that analysts can query without asking for help
- Own data quality checks and alerting for the pipelines you build

## Requirements

- 2 to 4 years of data engineering experience
- Strong SQL, including window functions and query optimisation
- Strong Python for pipeline development
- Hands-on experience building ETL or ELT pipelines
- Production experience with Apache Airflow
- Experience with data modeling for analytical workloads
- Bachelor's degree in Computer Science, Information Systems or a related field

## Nice to have

- Experience with Apache Spark
- Experience with dbt
- Experience with BigQuery
- Exposure to Apache Kafka for streaming
- Familiarity with Docker
