# Python Backend Developer

**Department:** Engineering
**Type:** Full-time
**Location:** Bangkok (hybrid)

## About the role

We are looking for a Python Backend Developer to join our platform team. You will
design and build the HTTP APIs that power our customer-facing products, own the
data model behind them, and keep the services reliable as traffic grows.

## Responsibilities

- Design, build and maintain REST APIs using Python and FastAPI
- Model and query relational data in PostgreSQL, including writing and reviewing migrations
- Collaborate with frontend engineers on API contracts
- Review teammates' pull requests and keep the Git history clean and reviewable
- Investigate production issues and improve observability

## Requirements

- 1 to 3 years of professional backend development experience
- Strong Python skills
- Hands-on experience building REST APIs with FastAPI
- Working knowledge of PostgreSQL
- Comfortable with Git-based collaboration
- Bachelor's degree in Computer Science, Computer Engineering, Information Technology
  or a related field

## Nice to have

- Experience containerising services with Docker
- Experience writing unit tests
- Exposure to Redis for caching
- Any experience with AWS
- Familiarity with CI/CD pipelines is a plus
