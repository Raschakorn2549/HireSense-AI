# Frontend Developer

**Department:** Engineering
**Type:** Full-time
**Location:** Bangkok (hybrid)

## About the role

We are looking for a Frontend Developer to build the interfaces our customers use
every day. You will work closely with design and backend engineers, and you will own
the quality of what ships to the browser, including accessibility and performance.

## Responsibilities

- Build responsive user interfaces with React and TypeScript
- Translate design files into accessible, semantic HTML and CSS
- Work with backend engineers to agree on API contracts
- Keep bundle size and render performance under control
- Participate in code review

## Requirements

- 1 to 3 years of frontend development experience
- Strong JavaScript fundamentals, including asynchronous code and the event loop
- Production experience with TypeScript
- Production experience with React, including hooks and component composition
- Confident with semantic HTML and modern CSS layout
- Bachelor's degree in Computer Science, Information Technology, Digital Media
  or a related field, or equivalent practical experience

## Nice to have

- Experience with Next.js
- Experience with Tailwind CSS
- State management with Redux
- Comfortable with Git-based workflows
- Experience writing unit tests for UI components
