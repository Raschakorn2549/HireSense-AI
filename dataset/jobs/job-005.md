# Full-Stack Developer

**Department:** Product Engineering
**Type:** Full-time
**Location:** Bangkok (hybrid)

## About the role

Our product squads own features end to end. As a Full-Stack Developer you will build
both the interface and the service behind it, and you will be responsible for the
feature working in production, not for handing it over.

## Responsibilities

- Build user-facing features with React and TypeScript
- Build and maintain the backend services behind them with Node.js
- Design REST APIs and the PostgreSQL schemas they read from
- Ship features behind flags and monitor them after release
- Take part in on-call rotation for the services your squad owns

## Requirements

- 2 to 4 years of experience shipping full-stack web applications
- Strong TypeScript across both frontend and backend
- Production experience with React
- Production experience with Node.js
- Experience designing REST APIs
- Working knowledge of PostgreSQL, including schema design
- Bachelor's degree in Computer Science, Software Engineering or a related field

## Nice to have

- Experience with Next.js
- Experience with Docker
- Any experience deploying to AWS
- Python for internal tooling
- Exposure to GraphQL
